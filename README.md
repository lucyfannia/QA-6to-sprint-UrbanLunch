# QA-6to-sprint-UrbanLunch

Proyecto de pruebas de la aplicación móvil Urban.Lunch (Android).

## Descripción
Se realizó la prueba de la primera versión de la aplicación para Android, usando Android Studio 64-bit. La app permite pedir comidas de diferentes restaurantes y recogerlas en puntos de la ciudad.

## Objetivo
Verificar que la aplicación cumpla con los requisitos funcionales definidos para la versión inicial.

## Actividades realizadas
- Análisis de requisitos de la aplicación.
- Creación de listas de comprobación (checklists) para pruebas.
- Pruebas funcionales en emulador Android Studio 64-bit.
- Registro de resultados: APROBADO / NO APROBADO.
- Reporte de errores en Jira.
